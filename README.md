# 系統設計學習筆記

繁體中文互動教材：16 章、81 個系統設計主題，含圖解、練習、搜尋與閱讀進度。

## 閱讀

GitHub Pages 發布後可直接線上閱讀。也可下載 `index.html`，使用瀏覽器離線開啟。

所有樣式、圖片與程式均內嵌。書籤與閱讀進度存在目前瀏覽器，不會跨裝置同步。

## 編輯內容

解壓縮 `system-design-source.zip`，編輯 `chapters/` 中的章節及 `source/` 中的樣式與程式。執行 `python build.py` 後，將產生的 `system-design.html` 複製為儲存庫根目錄 `index.html`，再提交更新。

原始檔不必轉成 Markdown；若未來要以 Markdown 管理長期筆記，可再分離內容與互動元件。
